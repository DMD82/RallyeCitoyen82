📊 Traitement des données
📥
Importer les notes ateliers
Lance importAtelierData() — lit tous les formulaires et peuple l'onglet "Note par Atelier".
➕
Calculer totaux et moyennes
Lance calculateSumsAndAverages() — peuple "Somme des Notes" avec les scores pondérés.
🏆
Générer le classement
Lance generateClassement() — écrit le classement final dans l'onglet "Classement".
✏️
Corriger le Fil Rouge
Lance corrigerFilRouge() — recalcule les scores du fil rouge depuis les saisies.
🔄
Mettre à jour les URLs ateliers
Lance updateWorkshopRatings() — synchronise les URLs de réponses dans l'onglet Ateliers.
🚩
Mettre à jour Fil Rouge (équipes)
Lance updateFilRouge() — synchronise les noms d'équipes dans l'onglet Fil Rouge.
🧹 Réinitialisations
🗑
Réinitialiser le Fil Rouge
Vide toutes les réponses de Saisie Fil Rouge et remet les scores à zéro dans Fil Rouge.
🗑
Réinitialiser les Bonus/Malus
Remet la colonne Comportement à 3 pour toutes les équipes dans l'onglet Fil Rouge.
🗑
Réinitialiser Note par Atelier
Vide l'onglet "Note par Atelier" (les données seront re-importées via les formulaires).
☢️
Tout réinitialiser
Vide Fil Rouge + Saisie Fil Rouge + Note par Atelier + Somme des Notes + Classement.
